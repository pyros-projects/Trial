Formula & file reference

Cell input: ' forces literal text · = starts a formula · signed decimals become numbers · TRUE/FALSE become Booleans · empty is blank · anything else is text.

SyntaxMeaning
2 3.5 -4finite decimal numbers
"text" "a""b"strings; doubled quote escapes
TRUE FALSEBooleans (case-insensitive)
A1 $A1 A$1 $A$1references; $ pins that part on paste
A1:B2range (only inside SUM/MIN/MAX)
+ - * /arithmetic (blank=0, TRUE=1, text→#VALUE!)
= <> < <= > >=comparisons: numeric for numbers/Booleans/blanks, case-sensitive for two strings, #VALUE! mixed
SUM MIN MAXscalars or ranges; ranges skip text/blank, keep errors; empty → 0
IF(cond,a,b)exactly 3 args; only the chosen branch is evaluated
#REF!error operand; also produced by pastes that rebase off-sheet

Precedence (high→low): parens/functions, unary +-, */ , +-, comparisons. Binary ops associate left-to-right. Errors: #DIV/0! #REF! #NAME? #PARSE! #VALUE! #NUM! #CYCLE!.

}

CSV: import replaces all cells and clears charts; finite numeric fields become numbers, other non-empty fields (incl. =…) are literal text, empty fields are blank. Export writes evaluated values with standard quoting.

Storage: everything lives in this document's memory. A fresh load always opens the seed workbook — export JSON to keep your work. No cookies or local storage are used.
