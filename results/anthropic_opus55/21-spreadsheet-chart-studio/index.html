Formula reference

Typing into a cell

  • = starts a formula; a leading ' forces literal text ('=1+1, '007).
  • Numbers like 42, -1.5, 2e3; TRUE/false are Booleans; empty is blank; anything else is text.

Operators, highest first (left-associative)

  1. ( ) and function calls
  2. unary + -
  3. * /
  4. + -
  5. = <> < <= > >=

References and functions

  • A1 is relative; $A1, A$1, $A$1 fix the column/row when pasted. A reference pushed off the sheet becomes #REF!.
  • SUM, MIN, MAX take values or ranges (A1:B3). Ranges skip text and blanks, count TRUE as 1, and pass errors on. No numbers gives 0.
  • IF(condition, then, else) evaluates only the chosen branch. 0/blank is false; text is #VALUE!.
  • Arithmetic: blank = 0, TRUE = 1, FALSE = 0, text is #VALUE! (numeric text such as "5" counts as 5). Comparisons: number/Boolean with number/Boolean, text with text (case-sensitive).

Errors

#DIV/0!
division by zero
#REF!
reference outside A1:Z100, or a #REF! operand
#NAME?
unknown function
#VALUE!
wrong kind of value, range outside SUM/MIN/MAX, wrong argument count
#PARSE!
formula syntax is malformed
#NUM!
result is not a finite number
#CYCLE!
circular reference (and anything depending on it)

Keys

  • Arrows, Tab, Enter move (Shift reverses Tab/Enter; Shift+arrows, Shift+click or drag extend).
  • Type to replace, F2 or double-click to edit, Alt+Enter for a new line, Esc cancels.
  • Delete clears; Ctrl+C / Ctrl+V copy and paste inside the app; Ctrl+Z / Ctrl+Y undo and redo.

CSV import replaces every cell and removes charts: numeric fields become numbers, all other fields literal text (even =1+1). CSV export writes calculated values. At most 100 rows × 26 columns.
