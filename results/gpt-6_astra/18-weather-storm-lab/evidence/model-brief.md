API exact:
Global class Atmosphere and constants DEFAULT_PARAMS. Browser-compatible script, also export via `if(typeof module!=='undefined')module.exports={Atmosphere,DEFAULT_PARAMS};`.
`new Atmosphere({n:32,l:12,seed:4821,preset:'supercell',params:{}})`
Properties n,l,seed,preset,params,time (simulated seconds),steps,rngState; arrays Float32Array t,q,c,r,u,v,w,p of size n*n*l, index=x+n*(z+n*y); t Celsius; q vapor g/kg; c cloud g/kg; r precip condensate g/kg; u/v horizontal m/s; w vertical m/s; p pressure anomaly hPa. Terrain Float32Array terrain and moisture size n*n indexed x+n*z; Uint8Array surface type 0 grass,1 lake,2 forest,3 city,4 ocean. Terrain in render-world height units 0..3.8. World x,z [-16,16], y [0,12] equals physical altitude [0,6]km. Grid fields absolute altitude. Terrain affects near-ground flow/uplift and surface sources.
DEFAULT_PARAMS numeric: dt:3,substeps:2,wind:14,rotation:0.3,lapse:6.5,humidity:82,evaporation:1,condensation:1,precipitation:1,buoyancy:1,diffusion:0.12,terrainInfluence:1,lightning:0.35. params are mutable. dt range .25..12, substeps1..8, wind0..45, rotation-2..2,lapse2..12,humidity10..110,evaporation0..4,condensation.65..1.3,precipitation0..4,buoyancy0..3,diffusion0..1,terrainInfluence0..3,lightning0..1.
`step(dt=this.params.dt)` advances exactly dt simulated seconds using substeps and any adaptive stability subdivision. Meaningful atmospheric transport, diffusion, surface evaporation, cooling under uplift, condensation transfers q->c, latent heating/buoyancy, rain formation and sedimentation with evaporation, dissipation, pressure forces/Coriolis, terrain uplift. Numeric bounds finite. Stats cfl real and adaptive count truthful.
`stats()` returns {temperature,humidity,cloud,cloudCover,rain,precipTotal,maxUpdraft,wind,pressure,vorticity,cfl,substeps,charge} meanings: mean temperature, mean RH percent, mean cloud, cloudCover horizontal fraction with column cloud>threshold, mean rain, cumulative mean ground precipitation mm, max w, mean hypot(u,v),mean p,max abs vorticity,actual cfl,actual last substep count,storm lightning proxy0..1. Include finite flag if useful.
`sample(wx,wy,wz)` returns {temperature,humidity,vapor,cloud,rain,u,v,w,pressure,buoyancy,vorticity,terrain,moisture} interpolate nearest sufficient. Pressure may full hPa (base hydrostatic + anomaly); ensure documented. `column(wx,wz)` returns array bottom->top same values plus altitude km. qSaturation(t) method or static allowed.
`brush(tool,wx,wz,radius,strength,elapsed=0.1)` continuous physical perturbation over horizontal radius world units; vertically weighted heat/cool/moisture/dry/wind/pressure/cloud. tools strings 'heat','cool','moisture','dry','wind','pressure','cloud','raise','lower','lake','forest','city','ocean'. elapsed real seconds; clamp so input continuous and dt independent. strength range .1..3, radius .5..5. Return number touched optional. Modify fields directly so paused brushes inspectable; heat plume delayed response comes from step afterward. Wind +u and some tangential component; pressure negative p. Types affect evaporation/albedo/thermal source. In brush do NOT advance time.
`serialize()` returns plain JSON object including schema:'weather-lab',version:1, every deterministic field/parameter,terrain,moisture,surface,rng,time,steps,precipTotal and preset/seed/dimensions.
`Atmosphere.fromState(object)` validates complete state fully before returning new instance; reject invalid/missing/nonfinite arrays, unsupported n/l, out-of-range params, bad types/size, >32MB input handled parent. n allowed24,32,48,64;l allowed8,12,16,24. Reject impossible values/bad rng etc. Restoring must yield identical next-step fields.
`resize(n,l)` preserve time/params/preset and resample fields & terrain; can return new Atmosphere or mutate, document chosen. Parent easiest uses `sim=sim.resize(...)`.
Preset ids: cumulus,sea,mountain,squall,supercell,cyclone,front,heat,snow,stress. Distinct deterministic fields and coherent control configs. Default supercell must have immediate visible isolated developed cloud masses (c 0.5..3 roughly between y world 3..10), localized precipitation, strong updraft/rotation, low storm pressure, open patches for terrain; no solid blanket uniform cloud. Initial terrain a lush rugged island with shoreline and mountain ridge toward rear (+z), water around edge and river if feasible. Storm remain compelling after >1000sim seconds.
