# Task 1: pure physics engine
Implement evidence/physics.js and evidence/physics.test.cjs. Do not touch index.html. No subagents. First write meaningful failing tests, then implement. Files are development intermediates; root will embed JS verbatim into the self-contained HTML.

Expose globalThis.Orbital = {clone, accelerations, step, advance, predict, invariants, elements, frame, transform, transformVelocity, scenario} with no browser dependencies. Use an IIFE; no modules/imports. clone uses JSON-compatible state cloning.

Body schema: {id,name,type:'star'|'planet'|'moon'|'craft',mass,radius,scale:1,x,y,vx,vy,color,primary:null|string,alive:true}. State {bodies, time:0, nodes:[], events:[], energyOffset:0, momentumOffset:{x:0,y:0}}. Node {id,craftId,primaryId,time,prograde:0,radial:0,dx:0,dy:0,mode:'orbital'|'cartesian',executed:false}. Orbital basis: prograde along relative velocity, radial outward; negatives allow retrograde/inward. Baseline invariants computed by UI. Burns log {type:'burn',time,nodeId,craftId,dvx,dvy,dv} and update offsets so numerical error excludes intentional energy/momentum changes. Collision log type:'collision',time,ids; behavior 'merge' preserves mass/momentum and absorbs smaller id into larger; 'bounce' elastic contact; 'pass' ignores contact. Keep surviving primary IDs valid after merge. Close approaches use softening epsilon in force and potential.

Options cfg {G:1,dt:0.04,softening:0.02,collision:'merge',horizon:220,resolution:400}. `step(state,h,cfg)` velocity Verlet and collisions, increments time; no nodes. `advance(state,duration,cfg)` subdivides duration by dt and a conservative encounter dynamical-time bound, splits precisely at scheduled node times, returns integration substep count. Never silently skip simulated time. Clamp reasonable minimum substep and report numerical failure by thrown error rather than NaN. Bodies all affect each other including craft. `predict(state,cfg)` clones state and integrates same dynamics through cfg.horizon, returning {samples:[{time,bodies:<cloned body array>}],events,closest:[{craftId,bodyId,distance,time}],final:<state>} including initial sample; output cfg.resolution+1 samples. Closest for each craft to each non-craft except its primary? include primary too, UI may filter. `invariants(state,cfg)` returns {energy,px,py,angular,kinetic,potential}; `elements(body,primary,cfg)` returns {distance,speed,energy,angular,eccentricity,periapsis,apoapsis,period,semiMajor} use null for undefined/unbound values; include eccentricity vector ex,ey if useful.

`frame(state,mode,selectedId,primaryId)` returns {x,y,vx,vy,angle,omega}. mode inertial: zeros; body: center primaryId; selected: center selectedId; rotating: center primaryId and align its first child moon on +x, omega from relative angular velocity. transform(body,frame) returns {x,y} rotated into frame; transformVelocity(body,frame) returns {x,y} after subtracting origin velocity and omega cross r then rotating. Each past/future sample can call frame on its own body array to avoid incoherent trails.

`scenario(key)` returns {state,cfg,title,description,selectedId:'odyssey',primaryId:'terra',view:{scale:2.6}}. Keys circular, elliptical, hohmann, moon, slingshot, threebody, escape. Typical defaults: helios mass10000 radius25 at(0,0); terra mass100 radius8 at(1000,0) velocity(0,sqrt(10)); luna mass0.8 radius2.2 relative radius80, relative circular velocity sqrt(100/80); odyssey mass0.00001 radius0.3 relative radius30 and circular speed sqrt(100/30). Assign attractive semantic colors star #ffc876, planet #64b9ba, moon #b9b8b0, craft #9ce9db. Recenter total momentum at zero. Main default circular parking orbit; tune initial angles so projected paths and moon legible. Orbit inclination is in-plane only. Make seven distinct physically meaningful presets, Hohmann has scheduled transfer burns, moon has moon-reaching apoapsis, slingshot encounters moon, escape exceeds primary escape speed; unstable threebody uses comparable perturber masses.
