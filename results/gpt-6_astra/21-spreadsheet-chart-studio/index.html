    A small guide to the studio

    Make yourself at home

    Click a cell, or enter A1:C3 in the address box to select a range. Drag or Shift-click to extend a selection. Type to replace; double-click or F2 to edit. Enter moves down, Tab moves right, and arrow keys navigate. Shift + arrows extends a selection. Escape cancels an edit; Alt + Enter inserts a line break. Apply commits the formula bar.
    Copy/Paste uses an internal snapshot, with no system clipboard. Ctrl/Cmd C, V, Z and Shift Z work on the grid. Delete clears a selection. Each paste, clear, import or chart edit has one undo step. Reset restores the example and clears history.

    Formulas, without the mystery

    =A1*B1Calculated from other cells
    =SUM(A1:B4, 2)Sum a range and scalar values
    =MIN(A1:B4) / MAXSmallest / largest value
    =IF(A1>0, 10, 1/0)Only the selected branch is evaluated
    =$A1+B$1+$C$1$ keeps that row or column fixed on paste
    Supports decimal numbers, TRUE/FALSE, text in double quotes (escape a quote as ""), parentheses, unary signs, + - * /, then comparisons = <> < <= > >=. Operators at each level read left to right. Ranges are accepted only by SUM, MIN and MAX. Start an input with an apostrophe to force text.
    Blanks count as zero in arithmetic. Booleans count as 1/0. Ranges ignore blanks and text; scalar text gives #VALUE!. Comparisons of two strings are case-sensitive; mixed string/numeric comparisons give #VALUE!. Formula names and references ignore case.

    When a cell needs attention

    #DIV/0! division by zero · #REF! outside A1:Z100 · #NAME? unknown function · #PARSE! malformed formula · #VALUE! wrong type or argument count · #NUM! nonfinite result · #CYCLE! active circular reference. The inspector shows actually evaluated references. Correct the input to recover.

    Charts follow the cells

    Charts use only numeric values. Zero is a point; blank, text, Boolean and error cells are omitted with a reason. Missing line points leave gaps. Hover or focus a point to inspect its value and source; click or press Enter to select that cell. Changes to settings apply together with Apply changes. Drag the divider, or focus it and use arrow keys, to resize the workspace.

    File format · Studio JSON v1

    {
  "format": "spreadsheet-chart-studio",
  "version": 1,
  "name": "My workbook",
  "cells": {
    "A1": {"type": "number", "raw": "2"},
    "B1": {"type": "formula", "raw": "=A1*3"},
    "C1": {"type": "text", "raw": "=literal"}
  },
  "charts": [{"id": "chart-1", "title": "Example",
    "type": "column", "range": "H1:J4",
    "colors": ["#297f72", "#a6afe3"], "legend": true}]
}
    Cells are sparse; omitted cells are blank. Supported types: number, text, boolean, blank and formula. Every raw input is a string. Text may have an initial apostrophe (removed when displaying), or be stored directly as literal text. Numeric and Boolean raws must match their declared type; blank raw is empty; formula raw begins with =. Calculated caches are ignored. Cell keys are uppercase addresses in A1:Z100. Chart IDs are unique, types are column/line, ranges are in bounds with at least two rows and columns, and each series has one hex color. The importer validates everything before replacing the workbook.

    CSV and keeping your work

    CSV supports quoted commas, doubled quotes and multiline fields. Finite signed decimal fields become numbers; other nonempty fields, even those beginning with =, are literal text. CSV import clears charts. CSV export uses calculated values with standard quoting. No cookies, storage, account, clipboard, or internet is used. A fresh load always opens the example.
