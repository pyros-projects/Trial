# FERRO validation record

Agent-authored evidence, 2026-09-29. Delivered artifact: [index.html](../index.html). No evaluator-owned score or report was created. Scores visible in campaign screenshots are the game's own contract scores.

## Final result

**PASS:** the public gameplay checks, direct-file offline runtime, desktop/mobile interaction, and 19 simulation regressions. No known application failure remains from the checks performed. Audio playback was enabled and its live context inspected; audio listening and quality were **not-run**. Cross-browser and physical-device testing were **not-run**.

The artifact is one 147,328-byte HTML file containing all CSS, JavaScript, simulation, Canvas rendering, inline SVG icons, and procedural Web Audio. Evidence scripts and development drafts are outside the delivered file and are not runtime dependencies.

## Environment and method

- Installed `agent-browser 0.31.1`, Chrome 143.0.7499.40, Linux, headless. Read `.agents/skills/agent-browser/SKILL.md`, `agent-browser skills get core`, and `agent-browser skills get dogfood` before testing. Version-matched workflows: [core](logs/browser-core-workflow.txt), [exploratory testing](logs/browser-dogfood-workflow.txt).
- Direct navigation: `agent-browser --session ferro open file:///home/pyro/projects/naked/sol61/11-factory-automation/index.html`. No HTTP server was needed. External traffic was blocked using `network route 'http://**/*' --abort` and `network route 'https://**/*' --abort`.
- Desktop: `set viewport 1280 800`; narrow: `set viewport 390 844 2`, including DPR 2. Controls were exercised with labelled buttons, selects, real mouse movements/down/up, and keyboard input. Trusted native CDP input supplemented the CLI for touch and a held Space key.
- `Ferro.diagnostics()`, `Ferro.factory`, and `Ferro.cellToScreen()` were read to correlate real simulation state with rendered output and aim pointer input. Gameplay state was changed through the controls. Browser checks did not inject deliveries, modify contracts, or substitute synthetic DOM events for actual gameplay.
- Empty console/error output means no reported messages. Final [console](logs/final-console.txt) and [uncaught-error](logs/final-errors.txt) files are intentionally empty. Network logs contain file-document loads only, with no external requests.

## Failures, fixes, and retests

1. **Resize framing — FAIL → fixed → PASS.** Camera coordinates clipped structures after narrow resize. [Desktop](screenshots/resize-repro-desktop.png), [narrow](screenshots/resize-repro-narrow.png), [diagnostics](logs/resize-failure.txt), [actual reproduction video](videos-resize-repro.webm). Resize now refits after a major dimension change and preserves center for small changes. [Retest](logs/resize-retest.txt): zero clipped structures. Later balanced mobile production also passed.
2. **Density/accounting/import regressions — FAIL → fixed → PASS.** Density reduction could produce negative packet positions; analytics imports lacked validation; changing a committed recipe refunded inventory without reversing consumption. Queue spacing now uses the larger of capacity/current length, imports validate histories/power/analytics, and refunds reverse metrics. [Red](logs/regression-red.txt), [green](logs/regression-green.txt). A scope error in the accounting repair was caught and corrected before browser recipe testing.
3. **Immediate undo/redo — FAIL → fixed → PASS.** Redo stayed disabled until the next 250 ms refresh. [Failure](screenshots/redo-failure.png), [state](logs/redo-repro.json). Stack changes now refresh buttons synchronously. Immediate Undo → Redo passed in the editing retest. `redo-repro.webm` opened a fresh recording context and **did not reproduce the same failure**; it is inconclusive and is not counted as successful reproduction.
4. **Post-load camera/input drift — FAIL → fixed → PASS.** Hiding the autosave banner triggered a delayed resize, shifting the loaded camera and an immediate copy click. [Observed result](screenshots/copy-retest-failure.png). Factory replacement now resizes synchronously before restoring saved camera/rendering. Editing, persistence, and file-import retests passed.
5. **Modal footer clipping — FAIL → fixed → PASS.** Preset footer extended below the modal; apparent button-center clicks hit the backdrop. [Before](screenshots/preset-footer-before.png). Modal now has fixed header/footer and a scrollable body. Invalid seed, campaign/preset loading, narrow controls passed afterwards.
6. **Four fresh-review findings — FAIL → fixed → PASS.** Preset poles occupied essential belt cells and balanced lacked its circuit dock; excess wire filled shared assembly buffers and starved iron; undo replayed old inventories after delivery; incompatible packet fields could reach non-transport structures. Reproduced in [review red](logs/review-red.txt). Fixed routes/dock, separate bounded ingredient compartments, preserve live stock during configuration undo, restore deleted layouts empty, reject incompatible packet fields. [Review green](logs/review-green.txt), final 19-test suite, sustained circuit/motor campaigns, and genuine malformed-file retest passed. UI explains that construction undo restores layouts while live goods keep moving.

## Automation limitations and recovery

- CLI mouse coordinates must be integers; early decimal coordinates were rejected. Harness coordinates were rounded before pointer commands.
- `record start` creates a new context/tab whose file localStorage lacked the original named slots. Returned to the original context for persistence checks; this context change established no application save failure.
- CLI `download` reported “Download was canceled.” Native CDP behavior was enabled for the actual `browserContextId`; labelled exports were clicked with agent-browser, completed events/files inspected. The failed helper is not reported as passing.
- Relative upload paths in the final import checks led to an unresponsive renderer/CDP timeouts. `agent-browser doctor` passed. The same fixture pasted into the UI was rejected correctly. Absolute-path uploads then passed malformed-file rejection and exact valid-file restoration. [Initial timeout](logs/final-persistence.txt), [doctor](logs/browser-doctor-final.txt), [absolute-path check](logs/final-import-absolute-path.txt), complete retests above. Unresponsive test daemons were stopped. No app code was changed for this tool issue.
- CLI `keydown Space` emitted empty key/code values, while `press Space` worked. [Observed events](logs/keyboard-cli-diagnosis.json), [initial failed pan assertion](logs/final-input.txt). Native CDP `Input.dispatchKeyEvent` supplied the held key for real mouse dragging. Touch used native CDP because the CLI has no direct touch command. No DOM event was fabricated.
- CLI JSON object re-encoding rounded some utilization-history floats in the last decimal place, failing the initial strict transfer comparison. [Initial comparison](logs/final-transfer-cli-rounding.txt). Returning `JSON.stringify(Ferro.factory.dump())` as a string preserved browser serialization; the same strict full-state comparison passed. Expected quantities and simulation behavior were not relaxed.

## Coverage limits

No required public check remains blocked. Physical touch devices, other browsers, prolonged multi-hour loads, and audio listening were not tested. Results cover the observed Chrome flows and one stress case. Local autosave depends on browser localStorage permission; the UI provides portable JSON export when local saving is unavailable.
