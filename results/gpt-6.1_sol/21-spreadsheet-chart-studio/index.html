A LITTLE GUIDANCE

Formulas, made clear.

Start with = to calculate. Start with an apostrophe to keep literal text.

=A1*B1Arithmetic: + − × ÷, with parentheses.
=SUM(A1:B2)SUM, MIN, MAX accept scalars and ranges.
=IF(A1>0,10,1/0)IF evaluates only its selected branch.
=$A1+B$1+$C$1$ keeps a row or column fixed when copied.
="say ""hello"""Double quotes inside strings are doubled.
Values, comparisons & errors

Numbers, TRUE/FALSE, text, and blanks stay distinct. Blank references give 0; Boolean arithmetic uses 1 or 0. Text pairs compare case-sensitively. Mixed text and numeric comparisons give #VALUE!. Comparisons: =, <>, <, <=, >, >=.

Ranges work only as SUM/MIN/MAX arguments; they ignore text and blanks and include numbers and Booleans. Scalar text gives #VALUE!. Functions and references are case-insensitive.

#DIV/0! zero divisor · #REF! invalid reference · #NAME? unknown function · #VALUE! invalid type or argument count · #PARSE! malformed syntax · #NUM! nonfinite result · #CYCLE! active circular dependency.

Editing & keyboard shortcuts

Type or double-click to edit a cell. F2 edits the existing source. Enter moves down; Tab moves across. Shift + arrows or Shift + click extends a selection. Delete clears a range. Ctrl/⌘ C and V use the internal copy snapshot, without system clipboard access. Ctrl/⌘ Z undoes; Ctrl/⌘ Shift Z or Ctrl Y redoes. Escape cancels a cell edit. Alt + Enter adds a newline while editing.

JSON workbook format · version 1

Root fields: format: "spreadsheet-chart-studio", version: 1, name, cells, and charts. Each cell has address, type (blank, number, text, boolean, formula), and string raw. Raw uses the same input rules as the formula bar. Prefix literal formula-looking text with an apostrophe. Omitted cells are blank; exports include all 2600 cells. Cached values are ignored.

Each chart has a unique string id, title, type (column or line), range, an array of hex RGB colors (one per series), and Boolean legend. Ranges stay inside A1:Z100 and include at least two rows and columns. Invalid files leave the workbook and history untouched.

CSV & chart data

CSV supports quoted commas, doubled quotes, and multiline fields. Finite numeric fields become numbers; other nonempty fields become literal text, including =formulas and TRUE/FALSE. CSV replaces the cells and clears charts. CSV exports calculated values over the occupied rectangle.

Charts use calculated numbers. Zero is a point. Blank, text, Boolean, and error data are omitted with reasons; line charts leave a gap. Select a point to select its source cell. SVG and PNG downloads include current labels, axes, and legend.

Everything stays in memory. No account or storage required.
