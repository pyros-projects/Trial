
ISSUE-001 — WebGL shader link failure on direct-file launch. Reproduced with agent-browser open file:///.../index.html, screenshot initial-render-failure.png. Browser console: "Precisions of uniform 'u_pass' differ between VERTEX and FRAGMENT shaders." Root cause: default integer precision differs by shader stage; matching float precision alone is insufficient. Fix: specify matching highp integer precision in both stages. Retest required: direct file, rendered terrain, glError 0, no error overlay.

CHECK-DRIVER-001 — agent-browser mouse wheel dispatches wheel at (0,0), even after mouse move. Reproduced twice; event diagnostics recorded clientX=0/clientY=0/target with no id and prevented=false. wheel-repro.webm and wheel-before/after.png preserve the failed check. This was an automation-driver limitation, not a canvas handler failure. A Chrome Input.dispatchMouseEvent with native coordinates (810,420) through the existing agent-browser CDP session changed distance 43 -> 33.825 while leaving terrain fields unchanged. Supplement used only for native wheel/multi-touch; all normal navigation, labeled controls, screenshots and pointer editing use agent-browser. See native-wheel.json and tests/native-input.cjs.

ISSUE-002 — Primary buttons scroll out of view when adjusting physical parameters. While the Simulation panel was scrolled to Thermal and Erosion, clicking Reset was covered by the fixed sidebar heading. Reproduced (reset-covered-repro.log) and captured (controls-scrolled-before-fix.png). Fix: move pause/step/reset above the parameter scroller so they remain visible in every control tab. Retest: scroll parameters, change settings, reset/resume/step without scrolling back; full parameter-sensitivity flow.

ISSUE-003 — Thin-film deposition reversed bed exchange. Real browser with erosion=0, thermal=0, rainfall=12mm/s and evaporation=0 changed height checksum 40147.480916 -> 40147.446105, produced deposited=-0.001603795m³ and suspended sediment with zero erosion. Review confirmed a negative (sediment-capacity) in the shallow-film else branch. Four new numerical checks initially failed (review-regressions-red.log): thin-film nonnegative deposition, dry near height ceiling, deposition at ceiling, isolated-pool downsampling. Fixes: nonnegative bed exchange, deposition limited by remaining bed headroom while retaining excess suspended solid, conservative downsample distribution. Full numerical retest: 15/15 pass (review-regressions-green.log). Browser zero-erosion retest: unchanged height checksum and no sediment. Higher erosion: positive erosion volume; high evaporation: substantially reduced water. Details in browser-results.json.

Early touch-continuity-red/green logs used the wrong release and are NOT valid regression outcomes. A correct-driver regression is recorded separately.
