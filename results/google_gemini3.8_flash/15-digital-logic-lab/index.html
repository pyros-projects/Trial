Keyboard Shortcuts & Quick Guide

Simulation

  • Space: Run / Pause continuous clock
  • T: Step Clock Tick
  • E: Micro-Step Propagation Event
  • R: Reset Simulation state

Editor Controls

  • Drag from Port: Connect wire to target port
  • Click on Switch / Button: Toggle digital input
  • Delete / Backspace: Delete selected components or wires
  • Ctrl+Z / Ctrl+Y: Undo / Redo
  • Ctrl+C / Ctrl+V: Copy / Paste
  • Ctrl+A: Select All
  • Ctrl+D: Duplicate Selected
  • F: Zoom to Fit entire circuit
  • 1: Reset Zoom to 100%
  • Mouse Wheel: Zoom in/out at cursor
  • Middle Click / Space+Drag: Pan canvas
  • L: Toggle Logic Analyzer Waveforms

Digital Logic Levels

'1' High: Active / True
'0' Low: Ground / False
'Z' High-Z: Floating / Tri-state
'X' Contention: Conflict / Unknown
