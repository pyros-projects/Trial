Formula & Syntax Reference

Formula Grammar & Precedence

Formulas start with =. Double quotes with "" escaping denote strings. Case-insensitive TRUE and FALSE are Booleans. Precedence:

  1. Parentheses (...) and function calls
  2. Unary signs: +, -
  3. Multiplication & division: *, / (left-to-right)
  4. Addition & subtraction: +, - (left-to-right)
  5. Comparisons: =, <>, <, <=, >, >= (left-to-right)

Cell References

References use A1 notation from A1:Z100 with optional $ on column or row (e.g. $A1, B$2, $C$3). When copied & pasted, relative coordinates rebase; out-of-sheet references become #REF!.

Supported Functions

  • SUM(arg1, [arg2...]): Sums numbers and Booleans (1/0). Accepts ranges (e.g. C1:C2) which ignore blanks/texts. Returns 0 if empty.
  • MIN(arg1, [arg2...]): Minimum of numbers and Booleans. Returns 0 if empty.
  • MAX(arg1, [arg2...]): Maximum of numbers and Booleans. Returns 0 if empty.
  • IF(condition, then_expr, else_expr): Lazy evaluation. Evaluates only condition and selected branch. Errors in inactive branch are ignored.

Errors

#DIV/0! (division by 0), #REF! (out of bounds), #NAME? (unknown function), #PARSE! (syntax error), #VALUE! (type mismatch/wrong arg count), #NUM! (nonfinite number), #CYCLE! (circular reference).
