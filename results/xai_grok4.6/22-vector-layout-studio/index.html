    Shortcuts & limits

    V select · A node · R rect · O ellipse · L line · P path · T text · Space pan · Wheel zoom · Esc cancel

    Ctrl+Z undo · Ctrl+Shift+Z redo · Ctrl+D duplicate · Ctrl+G group · arrows nudge (Shift = 10)

    Shift click/marquee adds to selection. Path: click places anchors, drag pulls handles, click start point to close, Enter finishes open, Esc cancels unfinished path.

    Limits: 200 items, 32 anchors/path, 4 nested groups, 2000 characters/text, artboard 64–2048, export ≤ 4096 per side and 16,777,216 pixels. Coordinates must be finite; scale must be positive; singular transforms are rejected.

    Reset is a fresh-session boundary. Import never fetches remote URLs. Markup in text stays text.
