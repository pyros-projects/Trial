    What am I looking at?

    Every pixel is sphere-traced against a signed distance field built from your object list. Objects are folded in list order: each object's operation (union, subtract, intersect, and their smooth variants) combines it with the field so far. The first visible object is the base solid.

    Tips

    Smooth ops use the Blend k value of the object carrying the operation. The SDF slice view shows the raw signed field on a plane — warm colors are inside, cool are outside, the yellow line is the zero set. The Artifact Lab preset deliberately stresses the marcher (noisy distance fields, thin shells) so you can study banding and step artifacts.

    Scenes persist in localStorage; use Export/Import JSON to move them between machines. Nothing leaves your browser — there are no network requests.
