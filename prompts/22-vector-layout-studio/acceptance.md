# Public validation checks: Vector & Layout Studio

Perform these checks against the actual application using labeled controls, pointer gestures, keyboard input, and the files it really downloads. Inspector values, parsed project JSON, and live geometry diagnostics may corroborate an interaction; invoking internal mutation functions is not a substitute for doing it. Record observed outcomes and failed attempts. Do not hard-code these sequences or treat an attractive screenshot as proof of correct editing.

1. **Editable opening and offline delivery.** Open the default composition, select its shapes and text, and change both. Load the second composition and inspect its editable objects. Test direct-file opening and an opaque-origin iframe with `sandbox="allow-scripts allow-downloads"`, without `allow-same-origin`, external resources, or storage access. The editor must start and remain usable. Record blocked environmental checks honestly.

2. **Creation and coordinate continuity.** Create rectangles, an ellipse, a line, and text with the actual tools. Move and resize objects with handles, then refine values in the inspector. Pan and zoom, resize the browser, and drag again: the object must track the pointer without a jump or an accidental second transform. Check the document-space bounds against the visible geometry at both 1280 x 800 and 390 x 844. Exercise multi-selection, duplicate, delete, and keyboard movement without deleting an object while typing into a field.

3. **Snapping.** With grid snapping off and object snapping on, move an object's edge toward another visible object's edge at 100% and 200% zoom. A proposed position within 5 CSS pixels must snap and show the relevant guide; a position 8 CSS pixels away from every eligible target must not. Verify the final document coordinate, not only the guide. Then check grid snapping separately and ensure hidden objects and objects inside the moving selection do not attract the selection. Select a nested child through Layers and drag it: its ancestor groups must not act as snap targets; a nearby eligible sibling or external object still can.

4. **Alignment and equal gaps.** On a blank 1200 x 800 artboard, create three unrotated rectangles with bounds A=(40,60,80,40), B=(180,100,60,40), and C=(320,160,80,40), expressed as x,y,width,height in document units. Select all and align their top edges: every y must become 60. Distribute horizontally: A and C stay fixed, B moves to x=190, and both gaps become 70. Confirm that sizes and stacking order stay unchanged. An impossible equal-gap distribution must report why and leave the scene unchanged.

5. **Groups and transforms.** Group two contiguous sibling objects and confirm their world positions and paint order do not change. Translate, rotate, and uniformly scale the group through the controls; descendants must move together without drift. Record their world geometry, ungroup, and compare it within 0.5 document units, including a rotated child. Exercise a nested group and undo/redo around group and ungroup. Attempt grouping noncontiguous siblings or objects from different parents and verify a clear refusal without changing geometry, order, or selection. A selected ancestor and descendant must never receive the same transform twice.

6. **Actual curve editing and bounds.** Draw an open cubic path using the path tool and manipulate its anchors and handles. Use the numeric point controls to set endpoints (100,100) and (200,100), with outgoing/incoming controls (100,0) and (200,0). Its unrotated layout bounds must be approximately (100,25,100,75), within 0.5 document units, excluding stroke and handles. Move a control point and observe the curve and bounds change. Create and reopen a closed filled path, and edit a node after rotating or grouping the path. Confirm export retains its editable cubic geometry.

7. **Text and typography.** Edit multiline text, font family, size, weight, alignment, line height, and fill. Enter literal text such as `<img src=x onerror=alert(1)> & "layout"`; it must remain text in the editor, project JSON, and exported SVG, with no injected element, alert, or resource request. Confirm the displayed layout box and export agree after changing line breaks and rotating the text. Commit a text edit, undo it in one document-history step, and cancel another edit without changing the document.

8. **Layer order, visibility, and locks.** Overlap colored objects and reorder them through Layers; the occlusion in both the editor and export must follow that order. Hide an item, show it again, and verify it was not deleted. Lock an item and attempt canvas dragging, deletion, and a parent-group transform that would move it. Each must leave it unchanged and give understandable feedback. Unlock it and repeat the intended edit. Hidden items must not be hit-test targets; locked visible items must still export.

9. **Coherent history and cancellation.** Make one long drag, one slider scrub, a committed text edit, and a layer reorder. Undo and redo each completed operation as one unit, checking geometry, styles, hierarchy, and selection. Pan, zoom, and change selection between undo steps without consuming document history. Undo an edit, make a different edit, and confirm the old redo branch is gone. Cancel an in-progress drag with Escape and a pointer-cancel/focus-loss case; no partial geometry or extra history entry may remain.

10. **Project round trip and hostile inputs.** Download a project containing paths, styled text, nested transforms, hidden items, and locks. Change the document, reimport the downloaded file, and compare the scene and hierarchy. Mutate copies of that actual format to include malformed JSON, a duplicate ID, a cyclic parent relationship if the format uses references (otherwise excessive nesting), a non-finite number such as `1e309`, an unsupported item type, and a count or size beyond the stated limits. Reject each without losing the current document, selection, or undo history. Reject arbitrary SVG/HTML imports and remote resource URLs without fetching or executing them. If raster import is implemented, also test a valid local raster, a disguised non-image, and an image beyond its declared byte or decoded-pixel limits.

11. **Scene-derived preview and exports.** Change a shape, a Bézier handle, a text string, visibility, and layer order before exporting SVG and PNG. Open the downloaded files and inspect both their contents and rendering: they must show those changes, the artboard dimensions and background, and no editor handles or guides. Check PNG pixel dimensions at 1x and 2x, and check that the SVG contains vector geometry and safely escaped text rather than a screenshot of the workspace. Verify that controls prevent an oversized export or refuse it clearly without changing the document. Verify exported SVG has no script, event handlers, `foreignObject`, or external resource references.

12. **Session boundary and reset.** Modify a composition, import a project, and leave an edit or optional raster decode pending before using the visible Reset command. Reset must restore the initial composition and clear selection, history, transient UI, pending operations, and imported assets; no delayed callback may restore old content. Reload and reopen the delivered HTML and verify the same fresh start. Explicit project download/reimport must work with persistent browser storage unavailable. Record console errors, failed requests, and any remaining input or export limitations.
